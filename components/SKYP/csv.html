Export & Transfer Guide

How to get the CSV file from your mobile phone into the SK Web System.

Meet Maria. Maria is an enumerator who just finished profiling 50 youths using the offline Android App. Watch how she exports the data and transfers it from her phone to the PC.

Step 1

Export the CSV File

Once Maria has finished encoding all the paper forms into her Android app, she needs to save that data as a single file.

She opens the app, goes to the settings or main menu, and taps the "Export Data to CSV" button.

Step 2

Locate in File Manager

The app saves the file to the phone's internal storage. Maria opens her phone's "My Files" or "File Manager" app.

She navigates to the Downloads folder. There, she finds the newly created file named something like SK_Survey_Banate.csv.

Step 3

Transfer to Computer

Maria long-presses the CSV file and taps Share. She needs to get this file to the laptop/PC where the SK Uploader is open.

Recommended Transfer Methods:

  • USB Cable: Plug the phone into the PC, open "This PC," and copy the file from the Downloads folder. (Most reliable)
  • Bluetooth: Pair the phone to the laptop and send the file.
  • Messenger/Email: Send the file to yourself, then open Facebook/Gmail on the computer and download it.

Step 4

Upload to the Web System

Now that the file is on the computer, Maria opens the web browser and goes to the CSV Uploader link.

She simply drags and drops the SK_Survey_Banate.csv file into the dashed box and clicks "Upload to Google Sheets".

Done! The data is now live on the dashboard.
